## 6. 확인하지 못했거나 남은 항목

- Safari, Firefox와 실제 모바일 기기에서는 시험하지 않았다.
- 실제 스크린리더로 들어보지 않았다.
- 대량 데이터와 다수 동시 사용자 성능은 측정하지 않았다.
- 댓글을 삭제하면 포커스가 삭제된 버튼을 따라 사라져 문서 처음으로 돌아간다.
- 이미지는 파일 앞부분의 시그니처만 검사한다. 시그니처만 맞춘 가짜 이미지는 올라가지만, 이미지로만 제공되고 스크립트 실행을 막는 헤더가 붙는다.
- 로그인 실패 기록은 서버 메모리에 있어 재시작하면 초기화된다.
- 공개 배포 시 추가 작업이 필요하다. 가입 횟수 제한, 화면 응답의 보안 헤더(다른 사이트의 프레임 삽입 차단 등), HTTPS, 프록시 뒤 IP 설정, DB와 이미지 백업이 해당한다.
