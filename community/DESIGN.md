# 커뮤니티 사이트 화면 설계

- 버전: v1.0 (2026-11-05 사용자 승인)
- 기준 문서: `PRD.md` v1.0
- API 계약: `API.md`

## 1. 공통 레이아웃

**상단 메뉴**
- 비회원: 로고, 로그인, 회원가입
- 회원: 로고, 글쓰기, 저장한 글, 닉네임, 로그아웃
- 360px 화면에서도 메뉴를 숨기지 않고 한 줄에 표시하며, 닉네임은 말줄임 처리한다.

**스타일**
- 흰 배경, 어두운 회색 글자, 파란색 강조색 하나를 쓰는 단순한 화면으로 만든다.
- 본문 폭은 최대 800px이고, 좌우 여백은 모바일 16px이다.
- 버튼과 입력칸의 터치 영역은 최소 44px이다.
- 키보드 포커스 표시를 항상 보이게 한다.

## 2. 화면 목록

| ID | 화면 | 주소 | 접근 | 담당 기능 |
|---|---|---|---|---|
| S1 | 글 목록 | `/` | 모두 | FR-4, FR-7, FR-8 |
| S2 | 글 상세 | `/posts/:id` | 모두 (쓰기 동작은 회원) | FR-5, FR-6, FR-9, FR-10, FR-11, FR-12 |
| S3 | 글쓰기 | `/write` | 회원 | FR-3, FR-7, FR-9 |
| S4 | 글 수정 | `/posts/:id/edit` | 작성자 | FR-6, FR-9 |
| S5 | 로그인 | `/login` | 비회원 | FR-2 |
| S6 | 회원가입 | `/signup` | 비회원 | FR-1 |
| S7 | 저장한 글 | `/saved` | 회원 | FR-13 |
| S8 | 없는 페이지 | 그 외 | 모두 | 공통 |

회원 전용 화면에 비회원이 들어오면 S5로 보내고, 로그인 후 원래 화면으로 돌려보낸다.

## 3. 화면별 구성

### S1 글 목록
- 위에서부터 검색창, 카테고리 탭(전체·자유·질문·정보), 글 목록, 페이지 번호 순서로 놓는다.
- 글 한 줄: 카테고리, 제목, 댓글 수, 작성자, 작성일, 좋아요 수. 이미지가 있는 글은 사진 표시를 붙인다.
- 검색어, 카테고리, 페이지는 주소에 남겨서 새로고침과 뒤로 가기에도 유지한다. (`/?category=free&q=검색어&page=2`)
- 카테고리를 바꾸거나 새로 검색하면 1페이지로 돌아간다.

### S2 글 상세
- 위에서부터 카테고리, 제목, 작성자·작성일, 본문, 이미지, 좋아요·저장 버튼, 댓글 순서로 놓는다.
- 작성자에게만 수정, 삭제 버튼을 보여준다.
- 비회원이 좋아요나 저장을 누르면 S5로 보낸다. 댓글 입력칸 자리에는 로그인 안내를 보여준다.
- 좋아요와 저장은 누르는 즉시 화면에 반영하고, 실패하면 원래 상태로 되돌린 뒤 오류를 알린다.
- 삭제는 확인 창을 거친다.
- 줄바꿈은 그대로 보여주고, 본문은 일반 텍스트로만 출력한다.

### S3 글쓰기, S4 글 수정
- 입력 순서: 카테고리, 제목, 본문, 이미지
- 이미지는 선택 즉시 미리보기를 보여주고, 각각 제거할 수 있다.
- 파일 형식, 용량, 장수는 선택할 때 먼저 검사한다.
- S4에는 기존 내용과 이미지가 채워져 있다.
- 작성 중인 내용이 있을 때 다른 화면으로 나가면 확인 창을 띄운다.
- 등록 중에는 버튼을 비활성화해 중복 등록을 막는다.

### S5 로그인, S6 회원가입
- S5: 아이디, 비밀번호, 로그인 버튼, 회원가입 링크
- S6: 아이디, 닉네임, 비밀번호, 비밀번호 확인, 가입 버튼
- 입력칸 아래에 규칙을 표시하고, 오류는 해당 칸 바로 아래에 표시한다.
- 가입이 끝나면 바로 로그인 상태로 S1에 이동한다.

### S7 저장한 글
- S1과 같은 글 한 줄 형식을 쓰며, 최근 저장순으로 표시한다.
- 각 줄에 저장 취소 버튼을 둔다.

## 4. 화면 상태

| 상태 | 표시 |
|---|---|
| 불러오는 중 | 목록 자리에 "불러오는 중이에요" |
| 불러오기 실패 | 오류 문구와 "다시 시도" 버튼 |
| 제출 중 | 버튼 비활성화, 문구를 "처리 중이에요"로 변경 |
| 짧은 알림 | 화면 아래에 3초간 표시, 스크린리더에도 읽히도록 처리 |

## 5. 문구

### 빈 상태
| 상황 | 문구 |
|---|---|
| 글이 없음 | 아직 글이 없어요. 첫 글을 남겨보세요. |
| 검색 결과 없음 | "{검색어}"에 맞는 글이 없어요. 다른 검색어로 찾아보세요. |
| 댓글 없음 | 아직 댓글이 없어요. |
| 저장한 글 없음 | 저장한 글이 없어요. 마음에 드는 글에서 저장 버튼을 눌러보세요. |
| 없는 글·페이지 | 찾으시는 글이나 페이지가 없어요. 삭제되었거나 주소가 잘못되었을 수 있어요. |

### 입력 안내와 오류
| 상황 | 문구 |
|---|---|
| 아이디 규칙 | 영문 소문자와 숫자 4~20자로 입력해 주세요. |
| 닉네임 규칙 | 2~12자로 입력해 주세요. |
| 비밀번호 규칙 | 8~64자로 입력해 주세요. |
| 비밀번호 불일치 | 비밀번호가 서로 달라요. 다시 확인해 주세요. |
| 아이디 중복 | 이미 사용 중인 아이디예요. |
| 닉네임 중복 | 이미 사용 중인 닉네임이에요. |
| 로그인 실패 | 아이디 또는 비밀번호가 맞지 않아요. |
| 로그인 시도 초과 | 로그인 시도가 너무 많아요. 15분 후에 다시 시도해 주세요. |
| 제목 누락 | 제목을 입력해 주세요. |
| 제목 초과 | 제목은 100자까지 입력할 수 있어요. |
| 본문 누락 | 내용을 입력해 주세요. |
| 본문 초과 | 내용은 10,000자까지 입력할 수 있어요. |
| 카테고리 누락 | 카테고리를 선택해 주세요. |
| 댓글 누락 | 댓글을 입력해 주세요. |
| 댓글 초과 | 댓글은 1,000자까지 입력할 수 있어요. |
| 이미지 형식 | JPG, PNG, WebP, GIF 파일만 올릴 수 있어요. |
| 이미지 용량 | 이미지는 한 장에 5MB까지 올릴 수 있어요. |
| 이미지 장수 | 이미지는 글 하나에 5장까지 올릴 수 있어요. |
| 로그인 입력 누락 | 아이디와 비밀번호를 입력해 주세요. |
| 로그인 필요 | 로그인이 필요해요. |
| 로그인 만료 | 로그인이 만료되었어요. 다시 로그인해 주세요. |
| 권한 없음 | 내가 쓴 글과 댓글만 수정하거나 삭제할 수 있어요. |
| 잘못된 요청 | 요청 내용이 올바르지 않아요. |
| 서버 오류 | 문제가 생겨서 처리하지 못했어요. 잠시 후 다시 시도해 주세요. |

### 확인 창과 알림
| 상황 | 문구 | 버튼 |
|---|---|---|
| 글 삭제 | 이 글을 삭제할까요? 삭제하면 되돌릴 수 없어요. | 취소 / 삭제 |
| 댓글 삭제 | 이 댓글을 삭제할까요? | 취소 / 삭제 |
| 작성 중 이탈 | 작성 중인 내용이 사라져요. 나갈까요? | 계속 쓰기 / 나가기 |
| 저장 완료 | 저장한 글에 추가했어요. | - |
| 저장 취소 | 저장을 취소했어요. | - |
| 글 삭제 완료 | 글을 삭제했어요. | - |

## 6. 접근성

- 입력칸마다 라벨을 연결하고, 오류 문구를 입력칸과 연결한다.
- 좋아요와 저장 버튼은 눌림 상태를 스크린리더에 전달한다.
- 이미지에는 "{글 제목} 첨부 이미지 {번호}" 대체 텍스트를 넣는다.
- 확인 창은 키보드로 조작할 수 있고, Esc로 닫으며, 닫으면 포커스를 원래 버튼으로 돌린다.
