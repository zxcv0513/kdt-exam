- 작성일: 2026-11-05

표기: **[확정]** 사용자가 답변으로 정한 내용 / **[가정]** 작성자가 제안한 기본값으로, v1.0 승인으로 확정됨

## 1. 목표

주제 제한 없이 회원들이 글과 사진을 올리고, 댓글과 좋아요로 소통하며, 마음에 드는 글을 저장해 다시 볼 수 있는 간단한 게시판 사이트를 만든다.

## 2. 사용자

| 사용자 | 할 수 있는 일 |
|---|---|
| 비회원 | 글 목록·상세·댓글 읽기, 검색, 카테고리 탐색, 회원가입 |
| 회원 | 비회원 기능 + 글·댓글 작성, 본인 글·댓글 수정·삭제, 좋아요, 글 저장, 저장한 글 모아보기 |

- 주제: 범용 게시판 **[확정]**
- 비회원의 읽기 허용 **[가정]**

## 3. 기능 요구사항

우선순위: P0 = 첫 버전 필수. 사용자가 요청한 기능은 모두 P0로 둔다.

### 회원

| ID | 기능 | 동작 기준 |
|---|---|---|
| FR-1 | 회원가입 | 아이디·닉네임·비밀번호로 가입한다. 아이디와 닉네임은 중복될 수 없다. **[확정: 회원가입 방식]** |
| FR-2 | 로그인·로그아웃 | 새로고침해도 로그인 상태가 유지되고, 로그아웃하면 회원 기능을 쓸 수 없다. |

### 게시글

| ID | 기능 | 동작 기준 |
|---|---|---|
| FR-3 | 글 작성 | 회원이 카테고리, 제목, 본문을 입력해 글을 올린다. |
| FR-4 | 글 목록 | 최신순으로 보여주고 페이지를 나눈다. 제목, 카테고리, 작성자, 작성일, 댓글 수, 좋아요 수를 표시한다. |
| FR-5 | 글 상세 | 본문, 이미지, 댓글, 좋아요 수를 보여준다. |
| FR-6 | 글 수정·삭제 | 작성자 본인만 할 수 있으며, 서버에서도 권한을 확인한다. |
| FR-7 | 카테고리 | 글은 카테고리 하나에 속하고, 목록을 카테고리별로 볼 수 있다. **[확정]** |
| FR-8 | 검색 | 제목과 본문에 검색어가 포함된 글을 찾는다. 카테고리 필터와 함께 쓸 수 있다. **[확정]** |
| FR-9 | 이미지 첨부 | 글 작성·수정 시 이미지를 올리고 상세 화면에서 보여준다. **[확정]** |

### 소통과 저장

| ID | 기능 | 동작 기준 |
|---|---|---|
| FR-10 | 댓글 | 회원이 작성하고, 본인 댓글만 수정·삭제한다. 대댓글은 없다. |
| FR-11 | 좋아요 | 회원은 글마다 좋아요를 한 번만 누를 수 있고, 다시 누르면 취소된다. **[확정]** |
| FR-12 | 글 저장 | 회원이 글을 저장하고 취소할 수 있다. 저장 여부는 본인에게만 보인다. **[확정]** |
| FR-13 | 저장한 글 모아보기 | 상단 메뉴의 별도 페이지에서 저장한 글을 최근 저장순으로 본다. 원글이 삭제되면 목록에서도 사라진다. **[확정: 기능 / 가정: 별도 페이지 형태]** |

### 입력 제한 **[가정]**

| 항목 | 제한 |
|---|---|
| 아이디 | 영문 소문자·숫자 4~20자 |
| 닉네임 | 2~12자 |
| 비밀번호 | 8~64자 |
| 카테고리 | 자유, 질문, 정보 (고정) |
| 글 제목 | 1~100자 |
| 글 본문 | 1~10,000자, 일반 텍스트 |
| 댓글 | 1~1,000자 |
| 이미지 | JPG·PNG·WebP·GIF, 파일당 5MB 이하, 글당 5장 이하 |
| 목록 | 페이지당 20개 |

## 4. 비기능 요구사항

**기술 구성**
- React + Vite 화면, Node 서버, SQLite 저장소를 사용한다. **[확정]**
- 언어는 TypeScript를 사용한다. **[가정]** 프로젝트 규칙의 완료 조건이 `npm run typecheck` 통과이기 때문이다.
- 이미지는 서버의 로컬 폴더에 저장한다. **[가정]**

**보안**
- 비밀번호는 복호화할 수 없는 해시로 저장한다.
- 로그인 세션은 스크립트가 읽을 수 없는 HttpOnly 쿠키로 유지하고, 상태를 바꾸는 요청에는 CSRF 방어를 적용한다.
- 모든 입력과 권한을 서버에서 다시 검증한다.
- SQL은 파라미터 바인딩으로 실행한다.
- 본문과 댓글은 일반 텍스트로 출력해 스크립트 삽입을 막는다.
- 업로드 파일은 확장자뿐 아니라 실제 파일 내용으로 형식을 확인하고, 서버가 만든 파일명으로 저장한다.
- 로그인 시도 횟수를 제한한다.
- 비밀값은 환경변수로 관리하고 DB 파일, 업로드 폴더, `.env`는 git에서 제외한다.

**사용성**
- 모바일(360px)과 데스크톱 화면을 모두 지원한다.
- 키보드로 주요 기능을 쓸 수 있고, 입력 항목에 라벨을 제공한다.
- 로딩 중, 결과 없음, 오류 상태를 화면에 표시한다.
- 화면 문구는 한국어로 작성한다.

## 5. 제외 범위

첫 버전에 넣지 않는다. **[가정]**

- 관리자 페이지, 신고, 차단
- 소셜 로그인, 이메일 인증, 비밀번호 찾기
- 대댓글, 알림, 쪽지
- 서식 편집기(글자 꾸미기), 댓글 이미지
- 프로필 페이지, 회원 탈퇴
- 공개 인터넷 배포 (로컬 실행까지가 범위)

## 6. 성공 기준

1. FR-1~FR-13이 실제 화면에서 모두 동작한다.
2. 다른 회원의 글·댓글을 API로 직접 수정·삭제하려 하면 거부된다.
3. 같은 회원이 좋아요를 여러 번 보내도 한 번만 집계된다.
4. 제한을 넘는 입력, 허용되지 않은 파일, 형식을 위장한 파일이 서버에서 거부된다.
5. 스크립트가 들어간 글을 올려도 화면에서 실행되지 않는다.
6. 서버를 재시작해도 회원, 글, 댓글, 이미지, 저장 목록이 유지된다.
7. `npm run typecheck`와 `npm run build`가 통과한다.

## 8. 승인 시 확인할 항목

1. 비회원도 글을 읽을 수 있게 할지
2. 저장한 글 모아보기를 별도 페이지로 둘지 (대안: 화면 옆 패널)
3. 카테고리를 자유·질문·정보로 할지
4. 제외 범위에 꼭 넣고 싶은 기능이 있는지 (예: 관리자, 공개 배포)
5. TypeScript로 진행할지 (기존 `my-profile`, `react_exam`의 설정 파일은 JavaScript)
